# Reflection Template

Use this before proposing a durable improvement.

```markdown
## Reflection

Task:
Observed failure or correction:
Evidence:

Root cause:
Failure class:

Episodic memory:
- What happened in this specific case?

Semantic memory:
- What general rule should be remembered?

Procedural memory:
- What step should happen next time?

Candidate improvement:
Why this is not just "be more careful":
What proof would show it works:
```

Only semantic and procedural memory should be promoted into a reusable skill, checklist, audit, fixture, or test. Keep episodic memory out of durable files unless it is anonymized and needed as a minimal fixture.
