# Ohana Branding Set

Regenerated from `input/ohana-brand-reference.png`. Generated PNG app icons use only pure black `#000000` and pure white `#FFFFFF`. The mark bounding box is centered in the square canvas.

## Contents

- `input/ohana-brand-reference.png`: original reference image.
- `source/`: 1024, 2048, and 4096 px pure black/white masters.
- `app-icon/`: light and dark icon PNGs in common iOS/export sizes.
- `ios/`: Xcode app icon sets for light and dark variants.
- `svg/`: pure-fill vector paths for Figma/vector editing.
- `previews/`: quick visual preview.
