# 宪法差距盘点（Constitution Gap Inventory）

> 总览会话产出，2026-06-12。逐条对照 `docs/specs/product-foundation.md` 的 D1~D18 / G1~G10 与代码现状。
> 优先级：**P0** = 上架前必须；**P1** = 上架前应做（小改造/测试项）；**1.x** = 可推迟到联机版。
> 进度登记在 `docs/testing-progress.md`「建设工作」表；本文件是证据与验收标准的明细。

## 总体结论

宪法 28 条中：**18 条符合或基本符合**（经济防刷 D2/G3、透支防护 D13 前半、quest 离世过滤 G4 部分、多人类档案 D10、无 StoreKit 真钱 D2、单机 CloudKit 关闭 D4 等）；**3 条需要新建功能**（P0 建设模块）；**6 条需要小改造或验证测试**（P1）；**1 条可推迟**（合资流程）。

## P0 建设模块（上架前必须，走完整六步循环 + 规则书 + 对抗复审）

### GAP-1 联机功能门（D5 / D9 / G7）✅ 范围已拍板
- **现状**：FamilyTasks 从首页多处可达（`VerticalSolidHomeView*`、`FocusHomeAuxiliaryViews` 等）；设置页有云同步区块（`SettingsView+CloudSync.swift`）；CKShare 接受入口在 `OhanaCloudSharingAppDelegate`。
- **工作**：新建统一判定点 `OnlineFeatureGate`（即未来 EntitlementService 的雏形，首发恒为关闭）；收编三处联机面：FamilyTasks 全部入口、云同步设置区块、CKShare 邀请/接受路径（收到他人分享时得体提示"联机版即将推出"而不是崩溃或静默）；FamilyReports **保留照护周报、剥离悬赏榜**（悬赏部分随门隐藏；若剥离成本过高，模块会话上报后再议）。
- **验收**：全 app 无任何可达的联机面（路由审计 + 人工遍历）；门的判定点唯一（rg 证明无散落判断）；隐藏模块仍编译、测试保留。

### GAP-2 回收站（D8 / D16）
- **现状**：不存在。删除宠物 = 级联真删（`PetBasicInfoDetailView` 危险区域）；"清空所有记录"同样真删。
- **工作**：成员（宠物/人/植物）与珍贵档案（照片/时刻/文档/保单）及批量清空操作进回收站：tombstone 标记、30 天保留、可恢复、到期清理；单条高频流水二次确认直删但底层写 tombstone（不进回收站 UI）；回收站入口在设置；"删除一切数据"（隐私权操作）保持立即真删（G6）。
- **验收**：删除 → 回收站可见 → 恢复 → 数据完整性测试（含派生状态：提醒/任务/经济不复活错误状态）；30 天到期清理测试；schema 改动走 ArkSchemaV* 升版流程。

### GAP-3 自动备份（D11 / G10）
- **现状**：仅手动导出（`DataBackupRuntime` 后台导出 actor）；无自动调度、无 iCloud Drive 目标、失败无可见性。
- **工作**：定期自动备份到用户 iCloud Drive（文件形式，**不是** CloudKit 同步，不违反 D4）；默认开启、可关；备份失败用户可见（设置页状态 + 必要时温和提醒）；手动导出保留。
- **验收**：备份 → 擦除 → 恢复 → 数据完整的端到端测试；iCloud 不可用/空间不足的降级路径；备份内容覆盖审计（与导出完整性 G6 同标准）。
