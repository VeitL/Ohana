1. 设计原则

Ohana 的视觉应该轻快、亲近，但交互本质是高频照护工具。优先可扫描、可重复操作、少解释、多状态。

Density

信息密度优先

首页只回答“今天谁需要照顾、现在最该做什么、点一下如何完成”。避免常驻长教程、营销式标题和装饰性大模块。

Tone

圆润但克制

胶囊按钮、柔和圆角、轻量半透明表面是 Ohana 的基本语气。卡片可以温柔，但不要卡片套卡片。

State

状态可读

完成、进行中、异常、隐私、逾期都要用文字、图标、颜色共同表达。颜色不能成为唯一信息来源。

Theme

深浅色同步

背景、卡片、描边、文字、图表、控件必须一起响应主题。普通卡片和正文禁止硬编码纯白或纯黑。

Performance

性能稳定

首页、设置、表单和详情页避免高风险重型玻璃效果。大列表使用 `ScrollView + LazyVStack`，动效受低电量和 Reduce Motion 约束。

Surfaces

表面与圆角

  • 页面背景使用 `OhanaAppBackground` 或 GO 岛屿背景。
  • 业务表面优先 `goTranslucentCard(cornerRadius: 20)`。
  • 轻量控件优先 `goGlassBackground(shape)` 或 `goSelectableSurface`。
  • 页面级卡片圆角约 22，内嵌区域 12-14，列表行 14。
  • 原生 `.glassEffect()` 只在明确 iOS 26 迁移或内部测试页使用。

3. 组件规范

下面的实验台可以切换组件类型、语义状态和内容密度，用来快速对齐视觉状态。真实 SwiftUI 实现应复用现有 modifier 与组件，不直接复制 HTML 样式。

Buttons

按钮

  • 每屏最多一个 Primary CTA，使用 `goPrimary` 实色胶囊。
  • Secondary 用轻背景，适合取消、稍后、查看详情。
  • Destructive 必须二次确认，红色文字、浅红背景、红色描边。
  • 图标按钮用固定触控区，熟悉动作优先只放 symbol。
Sheets

Sheet / 表单

  • 标题明确，右上角纯 icon 关闭。
  • 底部主 CTA 固定；复杂长列表才用 `.large` detent。
  • 表单分区用轻量半透明块，不在 sheet 内套厚重卡片。
Feedback

Alert / Toast / Empty

  • Banner 用于长期可见提醒。
  • Toast 底部短反馈，2-3 秒自动消失，可带撤回。
  • 空状态 = icon + 标题 + 一句说明 + 一个主操作。

5. 交互与动效

动效使用 `GoMotion`，不要在高频页面随手新增一套 spring 参数。动效要服务状态变化，不做无意义循环。

GoMotion.page

页面级

详情层展开、页面转场、较大布局变化。`interactiveSpring(response: 0.5, dampingFraction: 0.82)`。

GoMotion.hero

核心卡片

首页卡片堆、头像主体、Today Focus 切换。保持短、稳、有重量。

GoMotion.fab

强调反馈

FAB 菜单、奖励弹出、较强反馈。用于少数高感知动作。

GoMotion.feedback

轻反馈

按钮、chip、segment、toggle 和轻量状态切换。

减弱动态与低功耗

首页和背景已考虑 `AppPerformanceMode.powerSavingKey`、低电量、`UIAccessibility.isReduceMotionEnabled`。新增大面积动画、粒子、背景动效前必须提供降级路径。

6. 可访问性与本地化

这部分直接影响后续 UI 自动化、模拟器调试和真实用户可用性。

Automation

可测试控件

关键按钮、sheet 关闭、主 CTA、列表行、卡片展开入口应补 accessibility label 或 identifier。模拟器自动化优先通过语义定位，不靠坐标。

Contrast

对比与触控

实色按钮文字必须高对比；图标按钮触控区 32-44pt；状态不能只靠颜色表达。

Localization

中文 / English / Deutsch

用户可见中文整句作为 key，英文和德文在各自 `Localizable.strings`。新增 Go Focus 文案应经由 `L10n` / `AppLocalizedText` 提供 fallback。

7. 实现映射

新增或重构 UI 时先找这些代码入口。只有当现有模式不足以表达真实复杂度时，才增加新抽象。

Ohana/Shared/Design/ColorExtensions.swift品牌色、GO UI token、深浅色语义色、alert token。
Ohana/Shared/Design/OhanaDesignSystem.swift`GoMotion`、`OhanaFont`、卡片 modifier、按钮 modifier、底部 tab 和通用视觉基础。
Ohana/Shared/Design/ArkBackgroundView.swift全局背景、GO 岛屿背景、低功耗和 Reduce Motion 降级。
Ohana/Features/Home/Views/VerticalSolidHomeView.swift默认首页：钱包卡片堆、展开态快捷操作、FAB 二级功能。
Ohana/Features/Home/Views/TodayFocusCard.swift今日核心任务卡，负责风险、任务、庆祝和欢迎状态。
Ohana/Features/QuickCare/Views/Quick*DetailSheet.swift快捷操作长按详情页族群，统一 sheet 结构、隐私、记录和历史展示。
Ohana/Features/*/Views/*Dashboard*.swift深数据页面：overview 大卡、bento 指标、图表、明细列表。
Ohana/Features/Settings/Views/SettingsView.swift设置行结构、语言、背景、备份、性能与内部工具入口。
