空碗

粮食圆点保持低透明度，表示还没有完成今天的喂食。

喂食图标动画

点击左侧图标测试状态切换。动效只作用在碗里的粮食圆点和完成角标，主体饭碗保持稳定。

  • 空碗 / 未打卡 粮食圆点低透明度并略微缩小，保留“这里会出现粮食”的暗示。
  • 投喂中 / 点击后的过渡 三个圆点按 40ms、120ms、200ms 依次落入碗里，从透明变成实色。
  • 已经喂食 / 已打卡 粮食圆点保持实色，碗内阴影出现，右下角显示完成角标。
  • 回到空碗 / 撤销打卡 粮食圆点淡出并缩回，完成角标消失，状态回到未打卡。

接入 SwiftUI 时的建议

用一次性状态动画触发，不做循环。完成态作为稳定状态保留；重新变成未完成时，再播放淡出。
